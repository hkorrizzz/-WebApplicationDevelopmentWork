**ZZZEST - Интернет-каталог женской одежды с избранным и страницами бренда.**

**Стек технологий**  
- Backend: PHP 8.x, PostgreSQL (PDO)
- Frontend: HTML5, CSS3, JavaScript
- Стили: самописные CSS, Bootstrap
- Хранилище: PostgreSQL

**Основной функционал**  
- Отображение товаров (фильтрация) по категориям (юбки, футболки, брюки, топы, аксессуары)
- Детальная карточка товара с описанием, ценой, размерной сеткой и наличием в магазинах
- Добавление/удаление товаров в избранное (хранятся в `localStorage`)
- Счетчик избранного на иконке сердца
- Модальное окно авторизации (тест: логин qwerty, пароль 1234`)
- Выезжающее меню-бургер с навигацией и каталогом
- Адаптивная верстка для мобильных устройств
- Статические страницы: "О нас", "Магазины" (написанная с помощью Bootstrap), "Блог"

**Структура**  
- styles/ — CSS
- JSCode/ — JS
- pictures/ — картинки
- phpCode/ — PHP-вставки
- connection.php — подключение к БД
